Kone Code: Interactive Code Execution & Student IDE Stack

Architecture target:Coding Education, Cloud IDEs & Real-Time Linting (Kone Code)

Summary

Kone Code powers interactive browser-based code editing, sandbox execution containers, and instant test-suite feedback for students across web dev, Python, and systems engineering.

Recommended Tech Stack

recommended_stack.sh
Frontend: React + Monaco Editor + TypeScript. Backend: Node.js (Vite) + Docker Container Isolation. Cloud Execution: AWS ECS / WebAssembly (Wasm).

Architecture Workflow

1. Frontend Tier: Monaco Code Editor with custom language server protocols (LSP) for live syntax highlighting and linting. 2. API Gateway: WebSocket server managing student session persistence and real-time code execution streams. 3. Sandbox Container Tier: Isolated Docker / WebAssembly runtime environments executing code with memory and execution timeouts. 4. Feedback Engine: Automated unit test parser comparing output against grading rubrics in real-time.

Engineering Checklist

Isolate untrusted student code execution inside memory-capped container runtimes.
Stream stdout and stderr output over WebSockets for zero-latency terminal feedback.
Cache static language syntax definitions to ensure snappy offline editor performance.
